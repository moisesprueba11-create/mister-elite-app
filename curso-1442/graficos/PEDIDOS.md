# Pedido de diagramas tácticos — Curso 1-4-4-2

> Encargo para el equipo de diseño. Cada entrada indica el **nombre de archivo exacto**, el **módulo** donde se usa y una **descripción** (posiciones, flechas, zonas). Todos los gráficos siguen el sistema visual y la leyenda del [README](../README.md).
>
> **Sistema visual común:** campo verde con franjas, líneas blancas correctas; jugadores propios = círculos azules con etiqueta de posición en blanco; rivales = círculos rojos con apóstrofo (`DC'`); portero = triángulo; balón = círculo blanco con detalle. Flechas: continua = movimiento sin balón; discontinua/punteada = pase; ondulada = conducción; curva doble = presión orientada. Título dentro del SVG y mini-leyenda cuando ayude.
