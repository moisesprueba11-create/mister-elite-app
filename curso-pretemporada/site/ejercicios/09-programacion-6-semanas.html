Programación completa · 6 semanas, sesión a sesión

Plan de referencia de 6 sesiones por semana (lunes a sábado), con las tareas propuestas de cada sesión, semana a semana. Sin gráficos ni explicaciones: solo el qué y el cuánto, listo para llevar al campo. Los códigos entre paréntesis remiten al Banco de 12 sesiones. Para frecuencias menores, ejecuta los días de carga alta y el amistoso, y manda el resto como trabajo autónomo.

Carga: 🟢 baja · 🟡 media · 🔴 alta · 🔵 partido · ⚪ descanso.

Semana 1 · Acumulación — base y tests (ACWR ref. 1,0)

Día Carga Tareas propuestas
LUN 🟡 Activación → Tests (30-15 IFT o Yo-Yo IR1, sprint 10/30 m, CMJ) → movilidad → wellness de partida (Sesión 0)
MAR 🔴 Calentamiento articular → rondo 4v1 → base aeróbica gran formato posesión 9v9 (4×6′, pausa 2′) → vuelta a la calma (A)
MIÉ 🟡 Prevención 12′ (Nordic + core) → técnica analítica (pase-control, conducción) → juego de posición 6v6+3 (3×5′) (E·G)
JUE 🔴 Calentamiento → base aeróbica 8v8 campo grande (3×8′, p2′) → fuerza general circuito 2 vueltas → ABP ofensivo básico (córners) (A)
VIE 🟢 Movilidad → rondo 5v2 alta densidad (series 1′) → posesión 7v7 a 2 toques → soltura (F)
SÁB 🔵 Amistoso 1 (rival suave) · minutos 45–60′ · probar principios de ataque y defensa
DOM ⚪ Descanso

Semana 2 · Acumulación — base + primer HIIT (ACWR ref. 1,08)

Día Carga Tareas propuestas
LUN 🟢 Reactivación post-partido → prevención 12′ (Copenhagen + isométricos) → rondos de circulación → movilidad (E)
MAR 🔴 Calentamiento → HIIT con balón 4v4 espacio reducido (4×4′, 1:1) → juego de posición 4v4+3 con progresión (B·G)
MIÉ 🟡 Activación con velocidad (aceleraciones 10–15 m) → técnica + finalización → posesión 8v8 (D·J)
JUE 🔴 Calentamiento → base/HIIT 6v6 (4×4′) → fuerza-potencia (multisaltos + sentadilla) → fase de salida de balón 11v8 (B·H)
VIE 🟢 Movilidad → rondo 5v2 → ABP defensivo (marcajes en córner) → soltura
SÁB 🔵 Amistoso 2 · minutos 60–75′ · subprincipios y conjunción de líneas
DOM ⚪ Descanso

Semana 3 · Transformación — intensidad y fases de juego (ACWR ref. 1,14)

Día Carga Tareas propuestas
LUN 🟢 Reactivación → prevención 12′ (Nordic + tobillo) → rondos + posesión media → movilidad (E)
MAR 🔴 Calentamiento → HIIT 4v4 + inicio RSA (transiciones, 6 sprints 5″/25″) → fase de juego: presión tras pérdida (B·C·I)
MIÉ 🟡 Activación + velocidad 20 m (pausa completa) → táctico: progresión por zonas → posesión 8v8 dirigida (D·G)
JUE 🔴 Calentamiento → fuerza-potencia → táctico intenso: salida + progresión 11v8 → finalización (H·J)
VIE 🟢 Movilidad → rondo 5v2 → ABP ofensivo (faltas laterales) → soltura
SÁB 🔵 Amistoso 3 (rival medio) · minutos 75–90′ · automatismos y balón parado
DOM ⚪ Descanso

Semana 4 · Transformación — RSA, velocidad y automatismos (ACWR ref. 1,09)

Día Carga Tareas propuestas
LUN 🟢 Reactivación → prevención 12′ → rondos de circulación → movilidad (E)
MAR 🔴 Calentamiento → RSA (3 series · 8 sprints 5″/25″ en transiciones) → partido dirigido 8v8 con pausas (C·K)
MIÉ 🟡 Activación + velocidad/COD → táctico: automatismos de ataque → finalización con criterio (D·J)
JUE 🔴 Calentamiento → fuerza-potencia → juego real: fases combinadas (salida-progresión-finalización) 11v11 (H·J·K)
VIE 🟢 Movilidad → rondo 5v2 → ABP completo (córners + faltas + saques largos) → soltura
SÁB 🔵 Amistoso 4 (rival fuerte) · once tipo 60′ + rotaciones · plan de partido
DOM ⚪ Descanso

Semana 5 · Realización — once tipo y ritmo de competición (ACWR ref. 1,07)

Día Carga Tareas propuestas
LUN 🟢 Reactivación → prevención 12′ → posesión media → movilidad (E)
MAR 🔴 Calentamiento → velocidad/potencia (sprints máx. 30 m, pausa completa) → partido dirigido 11v11 a ritmo real (D·K)
MIÉ 🟡 Activación → táctico fino: ajustes del modelo (presión, repliegue) → ABP afinado (I)
JUE 🔴 Calentamiento → HIIT corto de mantenimiento (3×3′) → ensayo del plan de partido · once tipo (B·K)
VIE 🟢 Movilidad → rondo 5v2 → estrategia (defensa de ABP rival) → soltura
SÁB 🔵 Amistoso 5 (rival fuerte) · once tipo 75–90′ · ensayo general
DOM ⚪ Descanso

Semana 6 · Realización — tapering y debut (ACWR ref. 0,68 · taper)

Día Carga Tareas propuestas
LUN 🟢 Reactivación corta → prevención 10′ → posesión → movilidad (volumen reducido) (E)
MAR 🟡 Calentamiento → velocidad breve (4–6 sprints máx.) → táctico: plan de partido del debut (D)
MIÉ 🟢 Activación → ABP ofensivo y defensivo del rival del debut → posesión ligera
JUE 🟡 Calentamiento → activación con intensidad (HIIT muy corto 2×3′) → ensayo once tipo · estrategia (B)
VIE 🟢 Activación pre-partido (MD-1) → velocidad de activación → balón parado → soltura · carga baja
SÁB 🔵 DEBUT · primer partido oficial
DOM ⚪ Descanso

Cómo escalar a menos sesiones: quédate con los días de carga alta (martes y jueves) y el amistoso; reparte ahí los contenidos prioritarios (un pico condicional con balón + un día de fuerza/velocidad + táctico) y manda la base aeróbica y la prevención como trabajo autónomo. La progresión de las 6 semanas (base → HIIT → RSA → velocidad → tapering) se mantiene igual.
