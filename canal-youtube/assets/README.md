# assets/

## Por qué los MP4 no están en este repositorio

La política de red de este entorno de ejecución **bloquea todos los dominios de HeyGen**
(`files2.heygen.ai`, `resource2.heygen.ai`, `app.heygen.com`, `api.heygen.com`). Las
herramientas MCP funcionan —por eso se pueden generar los vídeos desde aquí— pero la
descarga directa del archivo devuelve `403` en el proxy.

Consecuencia práctica: los vídeos se generan desde aquí, pero **se descargan desde
app.heygen.com**, no desde este entorno.

Para Shorts usa siempre la de subtítulos quemados. También genera un `.srt` aparte por si

sin leer a las 23:14, el reloj avanzando, el "visto" a las 9:02). Tal cual está es solo el
avatar hablando, y eso retiene peor y roza la política de contenido de IA sin valor añadido.
